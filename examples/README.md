# Editable examples

Open any `*.stratum.json` through File → Open project, then run analysis. These are model inputs, not precomputed animations.

| File | What it exercises |
|---|---|
| `atrium-six-story.stratum.json` | 84 joints, 174 frames, six rigid diaphragms, self-weight and other gravity/lateral loads, three cases and three illustrative combinations |
| `cantilever-tip-force.stratum.json` | A 3 m steel cantilever discretized into 12 elements, 12 kN downward free-end force, static and modal response |
| `fixed-fixed-udl.stratum.json` | One member, every physical end DOF fixed, −4 kN/m; verifies nonzero interior deformation with zero free DOFs |
| `released-end-udl.stratum.json` | Fixed parent joints and independent local R2 releases at both ends; verifies zero end bending moments and simply supported transverse response |
| `tip-mass-modes.stratum.json` | Zero member density, 100 kg translational tip mass, finite modal response with massless rotational DOFs; explicitly reports only three finite modes of six requested |

`reference-summary.json` is generated by `node tools/generate-examples.mjs`. The application does not load it. It records reference frequencies, residuals, sampled maximum displacement and global force/moment equilibrium for comparison. Guarded maximums and residuals have the interpretation documented in `docs/ANALYSIS.md`.
